# Changelog

## Не выпущено — аудит стабильности, 2026-11-11

- Сохранение свежих метаданных при повторном импорте конфигурации; SQL-ошибки откатывают весь канал.
- Ненулевые коды CLI при ошибках/пустой выборке, валидация запросов, защита курсора от повреждённых ответов.
- Атомарная замена файлов экспорта, приоритет реальных JSON-данных перед ленивой загрузкой демо.
- Чтение правил один раз на пакет и устранение повторных проходов Canvas по облакам.
- Исправления конфигурации и малых ML-выборок; безопасные ссылки карточек.
- Новые регрессионные тесты, README, шаблон .env, отчёт аудита и согласуемый план развития.


## 0.7.1 — 2026-11-03

- Защита от демонстрационной выдачи tgden: ответы с ID `demo-*` больше не попадают в `channel_candidates`.
- Если `/api/catalog` возвращает demo-fixture, адаптер пробует ограниченный legacy `/api/suggest`; если тот также возвращает demo-fixture, запрос завершается без записи данных.
- Источник-каталог в `channel_candidate_sources` теперь явно отмечает использованный endpoint (`tgden_api_catalog` / `tgden_api_suggest`).
- Добавлен SQL-файл для предварительной проверки и безопасной очистки ранее сохранённых demo-кандидатов.
- Добавлены регрессионные тесты на распознавание demo-fixture и fallback.


## 0.7.0 — единый каталог источников и Telegram Account Connector

- Добавлен общий каталог кандидатов с отдельными связями `channel_candidate_sources` и `channel_sources`.
- Добавлена интеграция с каталоговым API tgden `/api/catalog`; тематические и географические запросы вынесены в `config/discovery_queries.json`.
- Добавлен импорт CloudSeeding из пользовательского CSV/TSV/JSON-экспорта без обхода авторизации dashboard.
- Доработан Telegram read-only connector для резервного аккаунта: импорт подписок и поиск рекомендаций Telegram (`channels.getChannelRecommendations`) в preview/apply режимах.
- Для recommendation-запроса добавлен TLRequest fallback, если установленный Telethon не содержит сгенерированного метода.
- Добавлен fallback TGDen на старый `/api/suggest`, если экспериментальный `/api/catalog` возвращает 404/405.
- MTProto-чтение блокируется до закрепления ожидаемого Telegram ID в `.env`; это уменьшает риск случайного использования не того аккаунта.
- Ограничены пакеты MTProto, введены задержки и безопасная остановка на FloodWait.
- Валидация публичной страницы больше не отклоняет канал только из-за аудитории менее 300 подписчиков.
- Улучшена нормализация username: ссылки на сообщения, приватные invite-links и `t.me/c/...` не принимаются за публичные username.
- Импорт кандидатов переносит в `channels` описание, подписчиков и Telegram ID; Telegram ID используется для сопоставления при смене username.
- Расширен разбор названия канала из публичной шапки t.me.
- Добавлены тесты discovery-адаптеров и нормализации ссылок.
- При повторном обнаружении уже импортированного канала обновляются его метаданные и provenance без создания дубля.
- CLI `--help` больше не требует загруженного драйвера PostgreSQL.

## 0.6.0 — единый реестр кандидатов

- Добавлены таблицы кандидатов и источников обнаружения.
- Добавлен предварительный импорт кандидатов и статусы проверки.
- Добавлен базовый Telegram account connector.
- Добавлены рекомендации `channels.getChannelRecommendations` и ограниченный сбор публикаций через MTProto.
- Все MTProto-команды read-only: не вступают в каналы, не отправляют сообщения и не ставят реакции; для кандидатов и постов применены лимиты и обработка FloodWait.
- Добавлен пакетный импорт подписок `--limit/--offset`, чтобы обходить длинные списки диалогов порциями.
- Исправлена обработка 429/временных 403 при проверке кандидатов: временные ограничения не помечают их как окончательно удалённые.
- Добавлена общая нормализация счётчиков `K/тыс./млн/млрд`.
- Усилена защита пути Telethon-сессии; сессии остаются в `sessions/` и исключены из архива.
- При повторном обнаружении уже импортированного канала обновляются рабочие метаданные и история источников без создания дубля.
- Команда `--help` теперь не требует установленного драйвера PostgreSQL.
- Семантическая ML-карта требует явного подтверждения прав на весь набор данных с учётом условий Telegram.
- Существующая географическая классификация и карта сохранены.


## 0.7.3 — 2026-11-03

- Восстановлен прежний tgden endpoint `/api/suggest`; неподтверждённый `/api/catalog` больше не используется.
- Добавлена единая политика минимальной аудитории `MIN_CHANNEL_SUBSCRIBERS` (по умолчанию 1 000).
- Каналы ниже порога получают статус `rejected`; неизвестное число подписчиков оставляет кандидата `pending`.
- `candidate-import` блокирует импорт кандидатов с неизвестной или недостаточной аудиторией, включая `--include-pending`.
- В `channel_candidates` добавлено поле `validation_note`; миграция выполняется через `python main.py init-db`.
