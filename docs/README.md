## История

[Исторические отчёты](history/README.md), [аудит](AUDIT.md) и
[план развития](ROADMAP.md) сохранены для контекста. Старые эксперименты не являются
основным способом публикации текущей карты. Рабочие CSV, посты, ML-кеши и полные
выгрузки остаются локально, а не в Git. Отдельный очищенный публичный снимок
карты публикуется в `web/snapshot/`; [подробности](../web/snapshot/README.md).
