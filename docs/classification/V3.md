# Классификация V3: отрасли и география по назначению

Таксономия — **8**, форма проверки — **3**. Существующие ID тем, ручные
поправки и CSV версий 1/2 поддерживаются. Структуру PostgreSQL менять не нужно.

## Главный принцип

**Предметный канал не обязан иметь географию.** Банковское дело, кредитование,
промышленность, ВПК, космическая отрасль, авиастроение, ТЭК, транспорт, программирование
и другие отраслевые темы по умолчанию получают `geography_scope=nonlocal`.
Это «географическое деление не применяется», а не неопределённый регион и не
международный охват. Старое автоматически присвоенное поле `region` не меняет это.

Территориальная классификация по умолчанию применяется к общей повестке, политике,
международным отношениям, военной повестке, деятельности органов власти, ЧП,
городскому хозяйству и социальной поддержке. Явно локальные медиа и афиши также
сохраняют территорию. Список находится в `config/topics.json: geography_topics`.
Слово «новости» в отраслевом канале само по себе не включает географию.

Подтверждённая владельцем география и явный `geographic_scope` имеют приоритет.
Проверенную привязку не сбрасываем автоматически при смене политики.
Русский язык и исходное `country=RU` не доказывают общероссийскую повестку.
Фактическую географию подписчиков система не измеряет.

На карте нетерриториальные каналы имеют отдельный остров «Без территориальной
привязки», не смешанный с «География не уточнена». В тематическом режиме они
остаются в своих предметных группах без регионального дробления. В полностью
нетерриториальной подборке вместо географических переключателей выводится пояснение.

## Приоритетные направления

| Тема | ID | Граница с соседними темами |
|---|---|---|
| Кредитно-финансовая сфера | `credit` | Кредиты, займы, ипотека, МФО; узкая часть банковской сферы |
| Финансово-банковская сфера | `banking` | Банки, услуги, регулирование, платёжная инфраструктура |
| Деятельность органов государственной власти | `government` | Деятельность ведомств, не политическое мнение о них |
| Промышленность | `industry` | Широкая производственная тема, когда нет достаточного основания для уточнения |
| ВПК | `defense_industry` | Предприятия, технологии, вооружение и гособоронзаказ; не боевые сводки |
| Космическая отрасль | `space_industry` | Производство и отраслевые программы; не астрономия |
| Авиастроение | `aircraft_manufacturing` | Разработка и производство воздушных судов; не пассажирские перевозки |
| ТЭК | `energy` | Топливо, нефть и газ, уголь, электроэнергетика; не обслуживание дома |
| Транспорт | `transport` | Широкая отрасль и инфраструктура; не только личные автомобили |
| Авиатранспорт | `air_transport` | Авиакомпании, аэропорты, воздушные перевозки и эксплуатация |

Добавлена самостоятельная тема `emergencies` — ЧП и происшествия. Прежние общие
`aviation`, `space`, `auto`, `business` не удалены: они нужны для совместимости и
случаев без доказанного уточнения. Всего 64 темы и 19 крупных групп.

Связь `parent_topics` задаёт более широкие темы. Выбор «Промышленность» включает
ВПК, ТЭК, космическую отрасль и авиастроение; выбор банковской сферы включает
кредитование. Дополнительные независимые темы по-прежнему включаются отдельной
галочкой. Приоритетные группы идут первыми в фильтре.

Финансово-банковская сфера здесь — широкая навигационная рубрика финансовых услуг,
а не юридический тип организации. Отнесение кредитного канала или МФО к её
подтеме не означает, что организация является банком или имеет банковскую лицензию.

Определения доступны прямо в форме. Для органов власти нужны предметные признаки
или подходящее наименование; фраза «официальный канал» у частной компании не
означает госвласть. Эта рубрика не подтверждает подлинность аккаунта.

## Проверка без потери прежней работы

Сначала скачайте CSV из старой формы. Откройте обновлённую форму по прежнему
адресу в том же браузере либо импортируйте сохранённый CSV. Исходные CSV не
перезаписываются; состав, порядок и ключ LocalStorage сохранены.

Теперь есть отдельные подтверждения темы и географии. Изменение темы снимает
только тематическое подтверждение, изменение страны — только географическое.
Неполная страна блокирует подтверждение географии, но не стирает проверенную тему.
Кнопка «Регион не нужен» явно выбирает `nonlocal`; это действие ещё нужно подтвердить.
Импорт и скачивание не должны самостоятельно угадывать страну или исправлять ответ.

```bash
python scripts/classification_quality.py inspect --review reports/classification-reviewed.csv
python scripts/classification_quality.py apply --review reports/classification-reviewed.csv --dimension topic
python scripts/classification_quality.py apply --review reports/classification-reviewed.csv --dimension topic --apply
```

`inspect` собирает ошибки по всем строкам без записи. Без `--apply` выполняется
только предпросмотр. Можно отдельно импортировать тему, не применяя сомнительную
географию. Импорт всех полей по умолчанию остаётся строгим и атомарным.

После согласованного применения:

```bash
python scripts/sync_topics.py
python main.py export
```

Метрики используют только подтверждённые измерения. Если подтверждена лишь
крупная группа, отсутствие узкой темы не считается ошибочной меткой «неизвестно».

## Посты: отдельный эксперимент, не источник автоматических исправлений

Сначала можно прочитать существующие публикации из БД:

```bash
python scripts/classification_quality.py sample-posts --channel example --source database --days 30 --limit 12
```

Команда выполняет только SELECT с лимитом 500 исходных строк, исключает короткие
сообщения, рекламу и точные повторы, распределяет выборку по доступным датам.
Курсоры, публикации и каналы в БД не изменяются. Если данных нет, не происходит
автоматического перехода к сети. Для ограниченного публичного HTTP-сбора:

```bash
python scripts/classification_quality.py sample-posts --channel example --source http --pages 2 --limit 12
python scripts/classification_quality.py compare-posts --review reports/classification-reviewed.csv
```

Результат остаётся предложением (`applied=0`). Неоднозначные классификации отдельных
постов не голосуют за тему. Упоминание города не переносится в географию канала.
Быстрые репосты и немаркированную рекламу нельзя считать полностью отфильтрованными.
Несколько постов за один день не выдаются за репрезентативную историю.

## ML и честная оценка

Локальный линейный классификатор поддерживает `--target topic` и `--target group`.
При недостатке узкой разметки можно обучать крупные группы; их прогноз не выдаётся
за подтверждённую узкую тему. География для обучения темы не обязательна.

```bash
python scripts/classification_quality.py train --review reports/classification-reviewed.csv --target group --output models/group-model.json
```

Сохранены минимальные технические требования: 40 уникальных train, 10 test,
два класса минимум по 3 train. Это не гарантия достаточного качества. Модель
привязана к версии таксономии и не включается в карту автоматически. Порог не
подбирается по test. Реальное обучение требует достаточных проверенных примеров;
тесты на искусственных данных проверяют только работоспособность конвейера.

Следующий этап — сравнение линейной модели и языкового энкодера на проверенных
данных. Нейросеть и внешние API в этой доработке не подключались. Перед обучением
на текстах публикаций отдельно необходимо проверить условия использования данных.
Примеры, по которым меняли рубрики, относятся к разработочной выборке: для
окончательного вывода о точности понадобится новый независимый контроль.

Для следующей партии именно по приоритетным отраслям:

```bash
python scripts/classification_quality.py prepare --focus-groups finance,state,industry_group,transport --exclude-review reports/classification-reviewed.csv --size 100 --output reports/sector-review.csv
```

Исключаются только реально доступные подтверждённые темы из указанного CSV.
Если сохранена не вся работа из браузера, сначала скачайте полный CSV. Новая
выборка не заменяет старую, а отсутствие примеров нужной отрасли не восполняется
неподтверждёнными предсказаниями.
