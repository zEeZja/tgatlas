# Telegram Channel Atlas — patch 0.7.3

Патч расширяет поверх версии 0.7.1 и включает изменения из патча 0.7.2 (TGStat и импорт локальных списков), поэтому его можно применить и поверх проекта, на который 0.7.2 уже установлен.

## Что изменено

1. Восстановлен прежний рабочий интеграционный маршрут tgden `GET https://tgden.com/api/suggest?q=...`. Неподтверждённый `/api/catalog` больше не вызывается.
2. TGDen-ответ разбирается по группе `groups[key=channels]`, поддерживаются старые поля `username`, `sub`, `label`; приватные ссылки и не-канальные сущности отбрасываются.
3. Введён единый обязательный порог `MIN_CHANNEL_SUBSCRIBERS`, по умолчанию 1 000.
4. Порог действует на всех источниках, которые используют `db.upsert_candidate`: tgden, TGStat, CloudSeeding, ручные списки и Telegram-кандидаты.
5. Кандидаты ниже порога получают статус `rejected`. Если число подписчиков неизвестно, кандидат остаётся `pending` и не может попасть в `channels`.
6. `candidate-import --include-pending` не обходит порог: неизвестная или недостаточная аудитория всё равно блокирует импорт.
7. Добавлено поле `channel_candidates.validation_note`; схема мигрируется через `init-db`.
8. Исправлен разбор русских счётчиков вида `1,2 тыс.` для подписчиков.

## Применение на Windows

1. Сделайте резервную копию PostgreSQL и папки проекта.
2. Распакуйте содержимое ZIP в корень `telegram-channel-atlas`, сохраняя структуру папок и соглашаясь на замену файлов.
3. Не заменяйте существующий `.env` файлом `.env.example`.
4. Откройте свой `.env` и добавьте строку (если её ещё нет):

   ```ini
   MIN_CHANNEL_SUBSCRIBERS=1000
   ```

5. В активированном виртуальном окружении выполните миграцию:

   ```powershell
   python main.py init-db
   ```

6. Проверьте поиск одного запроса:

   ```powershell
   python main.py discover-tgden --query "новости Казани" --limit-per-query 20
   ```

7. Проверьте кандидатов и число подписчиков:

   ```powershell
   python main.py candidate-stats
   python main.py candidate-list --status pending --limit 30
   python main.py discover-validate --limit 30
   python main.py candidate-list --status all --limit 50
   ```

8. Перед импортом сначала выполните предпросмотр:

   ```powershell
   python main.py candidate-import --limit 100
   ```

   Только если список вас устраивает, выполните:

   ```powershell
   python main.py candidate-import --limit 100 --apply
   ```

9. После импорта пересоберите классификацию и карту обычными командами проекта.

## Важные детали

- Порог 1 000 включительный: канал с ровно 1 000 подписчиков проходит; с 999 — отклоняется.
- Если `t.me/s/` не отдаёт число подписчиков, канал остаётся `pending`; это не считается подтверждением.
- Старые 779 каналов в рабочей таблице `channels` автоматически не удаляются и не деактивируются. Порог гарантирует фильтрацию новых кандидатов на входе в рабочий каталог.
- `/api/suggest` — suggest/autocomplete-интерфейс, не массовая выгрузка полного каталога. Фактическую доступность и релевантность выдачи нужно проверить после установки.
- `.env`, Telegram session-файлы и локальные данные в патч не входят.
