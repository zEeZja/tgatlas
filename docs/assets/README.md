# Изображения документации

`preview.png` — снимок текущего интерфейса на демонстрационном каталоге.
Тест намеренно заменяет рабочую выгрузку ответом 404 и не использует посты,
локальные теги или опубликованные координаты владельца.

Пересоздать после установки npm-зависимостей и браузера:

```powershell
$env:ATLAS_REPO_SCREENSHOT = 'docs/assets/preview.png'
node tests/product-demo.cjs
```

При использовании системного Chrome задайте `CHROMIUM_PATH`.
Не заменяйте превью снимком приватных данных или служебных экранов с секретами.
