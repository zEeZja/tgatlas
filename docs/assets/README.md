# Изображения документации

`preview.png` — реальная опубликованная карта 3463 каналов из `web/snapshot/`.
Снимок сделан в чистой копии без рабочих данных и браузерных ручных исправлений.

После установки зависимостей и браузера, в чистой копии репозитория:

```powershell
$env:ATLAS_SCREENSHOT = 'docs/assets/preview.png'
node tests/published-layout.cjs
```

Для системного Chrome задайте `CHROMIUM_PATH`. Проверка сверяет точные
координаты t-SNE по HTTP и `file://`. Не добавляйте приватные данные на скриншот.
