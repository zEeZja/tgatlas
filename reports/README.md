# Рабочие отчёты

Здесь создаются CSV/HTML для ручной проверки, выборки постов, контрольные точки
сбора, ML-кеши, расчёты проекций и резервные копии публикаций. Всё это локальные
рабочие данные: в Git включён только этот README.

```bash
python main.py audit-classification --report reports/classification-review.csv
```

Не удаляйте папку ради повторного запуска: так можно потерять ручные ответы и
сбросить счётчики доступа. Используйте команды продолжения из
[актуальных инструкций](../docs/README.md). Снятие файлов с Git-отслеживания при
подготовке релиза не удаляет локальные отчёты и старые эксперименты.
