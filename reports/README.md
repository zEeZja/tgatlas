# Рабочие отчёты

Здесь создаются CSV для ручной проверки. Генерируемые отчёты не коммитятся: они зависят от вашей базы и могут содержать рабочий каталог.

```bash
python main.py audit-classification --report reports/classification-review.csv
```

Существовавшие до аудита снимки сохранены в [архиве](../docs/history/reports/), поскольку они могут содержать уникальные записи. Это исторические данные, а не актуальный результат проверки.
