# Публичная карта

**3463 канала**, классификация 11v2 и точные координаты t-SNE, зафиксированные
23 ноября 2026 года. Это снимок локальной опубликованной карты, а не демокаталог
и не данные в реальном времени. Дата отображается в справке интерфейса.

Сохранены публичные профили, аудитория, метки, географический охват и координаты.
Тексты постов, evidence, topic_diagnostics, сырые sources, контрольные точки,
cookies, пароли, БД и веса не публикуются. Факт использования постов в расчёте
не означает публикации их содержимого или независимой оценки качества.

`manifest.json` содержит число каналов, дату и SHA-256 источников/файлов.
JSON используется по HTTP, JS — при открытии через `file://`.
Локальная выгрузка в `web/data/` имеет приоритет, а её координаты не смешиваются
с этим снимком. Приватные ручные правки LocalStorage не включены.

Обновление владельцем из совместимых рабочих файлов:

```bash
python -B scripts/publish_public_snapshot.py
python -B scripts/publish_public_snapshot.py --apply
```

Первая команда — только проверка. Вторая записывает исключительно эту папку,
не меняя рабочие экспорты, БД и историю экспериментов. Проверьте diff и обновите
превью/дату документации перед коммитом. Не заменяйте снимок сырым экспортом.
