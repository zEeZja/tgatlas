# Локальные данные карты

Рабочие выгрузки не включены в Git. Без них интерфейс открывает отмеченный
демокаталог из `web/demo.js` (779 исходных записей, без выдуманной аудитории).

| Файлы | Назначение |
|---|---|
| `channels.json`, `channels.js` | Каталог; JSON для HTTP, JS для `file://` |
| `atlas_layout.json`, `atlas_layout.js` | Явно опубликованные координаты t-SNE |

Не заменяйте текущую карту случайным снимком БД. Используйте
[безопасное слияние и публикацию](../../docs/GROWTH_6000.md).
При обновлении старой установки исключение файла из Git не удаляет его с диска.
