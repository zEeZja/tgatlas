# TG Atlas — обновлённый интерфейс

Визуальная тема: графитовый фон, мятные акценты, координатная сетка и подписи регионов. Фронтенд остаётся на HTML, CSS и JavaScript, без сборщика и новых зависимостей для запуска.

## Быстрый просмотр

Из корня проекта:

```bash
python -m http.server 4173 --directory web
```

Откройте http://localhost:4173. Можно также открыть `web/index.html` напрямую.

В поставке нет рабочей выгрузки БД. `web/demo.js` содержит демонстрационный каталог из 779 записей исходного `config/channels.json`. Геопривязка рассчитана существующим классификатором проекта, 599 точек. Подписчики не придуманы: значения отсутствуют. Демо не подтверждает существование, актуальность или географию каналов; это явно указано в интерфейсе.

## Подключение рабочих данных

Сохраните свой `.env` и существующую папку `web/data`. При переносе дизайна в рабочую копию заменяйте только файлы непосредственно в `web/`; **не заменяйте свою папку `web/data` заглушками из архива**.

После настройки БД используйте прежние команды проекта:

```bash
python main.py build-geo-map
python main.py export
```

Рабочие `data/channels.js` и `data/geo_map.js` имеют приоритет над демо. Для HTTP API переключите `CONFIG.mode` в `web/api.js` на `http` и задайте `httpBase`, как и ранее. В режиме HTTP демонстрационный каталог не применяется.

В архив не включён `.env`; используйте исходный локальный файл настроек.

## Что добавлено

- Единое оформление каталога, карты, легенды и карточки.
- Кнопки приближения, отдаления и возврата к общему виду.
- Подписи регионов, скрывающиеся при пересечении друг с другом.
- Сортировка по аудитории и названию, кнопка загрузки следующих 200 строк.
- Поиск с `@username`, сброс фильтров и пояснение пустой выдачи.
- Переключение списка и карты на мобильном экране, перетаскивание касанием.
- Фокус на точке при выборе регионального канала из списка.
- Справка, клавиша `/` для поиска, `Esc` для закрытия карточки и справки.
- Доступные названия кнопок, индикация выбранных фильтров, поддержка уменьшения анимации.

Исправлены исходная ошибка ранней инициализации легенды и расхождения цветов между тематическими точками и легендой. После изменения фильтров карточка скрывается, если выбранный канал исключён из выдачи.

Федеральные каналы и записи без координат доступны через каталог. Контуры территорий не добавлены: карта показывает географическую раскладку по исходной проекции Ламберта и существующим данным проекта.

## Проверка

Проверено автоматизацией Playwright в Chromium: загрузка, поиск по @username, категории, регион, сброс, пустая выдача, сортировка, дополнительные страницы списка, выбор точки на Canvas, кнопки масштаба, справка, Escape, мобильная карточка и приоритет реальной выгрузки над демо. Проверены размеры 1440×1000, 1280×720, 768×1024, 390×844, 360×640; ошибок JavaScript не обнаружено.

Живая PostgreSQL и HTTP API не запускались: в приложенном архиве нет рабочей выгрузки. Backend не менялся.
